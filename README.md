 Consent-Based USB Activity Monitoring System 
I am an undergraduate Cyber Security student. I want to develop a Consent-Based USB Activity Monitoring System as a cybersecurity practical project using C# and Visual Studio on Windows.
Please act as my Cyber Security instructor and C# programming tutor and guide me from beginning to end.
Project Objective
I want to create a small defensive security application that:
1.Displays a clear consent notice before monitoring starts.
2.Starts monitoring only when the user selects Yes/I Agree.
3.Detects USB storage device connection and disconnection events.
4.Records only safe activity such as:
oDate and time
oUSB connected
oUSB disconnected
oMonitoring started/stopped
5.Saves these events in a local log file.
6.Calculates a SHA-256 hash of the log file to demonstrate data integrity.
7.Provides a simple report showing the recorded activities.
8.Allows the user to stop monitoring at any time.
9.Clearly informs the user what information is being collected.
Strict Privacy and Ethical Requirements
This is an educational cybersecurity project. The application must NOT:
Steal passwords
Capture keystrokes
Collect browser history
Read browser cookies or saved credentials
Copy personal documents
Take screenshots
Access webcam or microphone
Hide itself from the user
Bypass Windows security
Automatically execute malicious code from a USB
Send data secretly to another person
Monitor a computer without the user's knowledge
Use only a test/lab computer and dummy data.
